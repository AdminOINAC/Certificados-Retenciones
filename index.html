Guía de configuración
1

Registrar la aplicación en Azure

Ve a portal.azure.com → Azure Active Directory → Registros de aplicaciones → Nueva aplicación.

Nombre: Portal Certificados
URI de redireccionamiento: https://tu-sitio.com/
Permiso requerido: Files.Read.All

Copia el Client ID y el Tenant ID y pégalos en la sección de configuración del archivo HTML.

2

Estructura de carpetas en OneDrive

La carpeta raíz debe llamarse exactamente como configuraste en ONEDRIVE_FOLDER_PATH.

Certificados 2024/
  ├── 900123456/
  │   ├── RTF_900123456_B1_2024.pdf
  │   ├── IVA_900123456_B1_2024.pdf
  │   └── ICA_900123456_2024.pdf
  └── 800456789/
      └── RTF_800456789_B1_2024.pdf
3

Generar contraseñas en Excel

Usa esta fórmula para que cada proveedor tenga una contraseña única y fácil de enviar:

=CONCAT("CERT",DERECHA(A2,4),AÑO(HOY()))

Ejemplo: NIT 900123456 → contraseña CERT34562024

4

Publicar el portal

GitHub Pages (gratis): sube index.html + providers.json al repositorio → Settings → Pages → rama main.

SharePoint (ya incluido en M365): Documentos → Cargar página → pegar como página de SharePoint.

5

Notificar a los proveedores

Usa combinación de correspondencia de Outlook + Word con tu Excel de proveedores para enviar un correo masivo con URL del portal, NIT y contraseña asignada a cada uno.
